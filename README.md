# UV 贴图杂点检查

选择纹理图和对应的 UV 图，在 UV 覆盖范围内寻找局部偏暗、面积较小的疑似杂点，生成带编号的标注图和局部放大图。结果供人工复核，工具只添加标记，不修改原始纹理。

页面和检测算法使用纯 JavaScript、HTML、CSS 与 Canvas，无第三方运行依赖、无需构建，也不向服务器上传输入图片。

## 在线使用

打开 [UV 贴图杂点检查](https://edsver-sketch.github.io/uv-texture-inspector/)，无需安装或登录。图片仍在当前浏览器本地处理。

网站由 GitHub Pages 从 `main` 分支根目录自动发布；后续推送会更新网站。

## 本地使用

下载并解压仓库，在桌面浏览器中打开根目录的 `index.html`。

1. 选择要检查的 PNG 或 JPG 纹理图。
2. 选择与纹理使用同一布局的 UV 图。
3. 查看“UV 范围”，必要时将背景模式切换为透明、深色或浅色。
4. 选择检测范围，点击“检查杂点”。
5. 复核局部放大图，取消不需要的候选，再保存标注总图或当前页放大图。

普通浏览器会展示导出图片，可右键另存为。在提供相应接口的小红书小工具环境中，保存按钮会调用平台的相册接口；平台模拟器中的接口成功提示不代表真机相册已验证，也不代表已通过平台审核。

## 输入与检测范围

- **纹理图**：PNG、JPG；检测侧重局部偏暗的小色斑，不涵盖所有色彩错误。
- **UV 图**：优先使用包含岛面填充的透明 PNG；`alpha ≥ 64` 的像素会被保留。也支持对深色、浅色背景的 RGB/JPG 图片进行保守亮度分割。
- 两张图应有相同长宽比，且 UV 布局对应。尺寸不同时，UV 图会缩放到纹理尺寸；工具不会自动校正截图边框、偏移或旋转，建议使用相同像素尺寸的原始导出图。
- 只有线条的 UV 图片只能提供线条覆盖，无法恢复完整岛面；与背景同色的内容也无法从 RGB 图中恢复。使用原始透明 UV 图通常更可靠。

候选通过局部亮度差、噪声水平、连通块大小和形状筛选，并避开 UV 覆盖边缘。正常阴影、装饰和纹理细节也可能成为候选。检测尺度以输入像素为单位，改变图片分辨率可能改变结果。工具不读取三维模型，不能验证跨 UV 岛接缝、真实表面连接或材质语义。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `index.html`、`styles.css` | 本地页面与样式 |
| `app.js` | 图片导入、候选复核、图片导出和平台保存适配 |
| `uv-mask.js` | UV 图片覆盖提取 |
| `detector.js` | 岛内疑似暗色小杂点检测 |
| `tests/` | 程序合成数据的逻辑与界面事件测试 |

`uv-mask.js` 和 `detector.js` 兼容经典浏览器脚本，也支持通过 Node.js 的 `require()` 单独调用。

## 测试

安装 Node.js 18 或更新版本，在仓库目录执行：

```sh
npm test
```

不需要先运行 `npm install`。测试只使用程序合成像素，不包含用户 UV、纹理、模型或私人历史数据。覆盖透明 UV 的半透明岛面、深浅背景、线框保守处理、已知小暗斑、透明像素排除、UV 范围限制，以及导入、取消候选、恢复与保存适配等事件。

已通过 Node.js 算法测试、模拟 DOM/Canvas 事件测试（含候选跨页选择保持与恢复），以及桌面浏览器中的图片导入、检测、取消与恢复候选、标注总图和局部放大图导出流程。桌面浏览器模拟 320、390、768、1280 像素视口检查了响应式布局，320 像素视口使用合成图片检出 3 个候选并检查了候选和导出区。

小红书创作者平台模拟器中，手动导入一组 2K 实际纹理和 UV 图，识别覆盖率 66.7%，检出 55 处候选；已检查候选取消、跨页保持、恢复和三种预览模式。UV 背景从自动切换为透明后，旧结果清空、导出禁用，重新检测仍为 55 处。标注总图与第 2 页局部放大图的相册保存接口均显示成功。候选仍需人工复核；模拟器的成功提示不代表 Android 或 iOS 真机相册保存已验证。平台审核及手机真机测试尚未完成。
